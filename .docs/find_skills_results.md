# Find Skills Search Results

We used the `find-skills` Agent Skill to search the skills.sh directory for skills relevant to Python data analysis, data cleaning, statistical analysis, and data visualization. The search results below were retrieved from skills.sh pages and search results during the conversation.

The Skills CLI was not used because `npx` was unavailable in the environment.

## Best Fit for This Project

- **`data-analysis-jupyter`** is a strong fit because this project uses Python and Jupyter Notebook, and the skill specifically supports those workflows with common analysis and visualization libraries.
- **`statistical-analysis`** complements it by providing focused guidance for statistical tests, regression, correlation, assumption checking, and uncertainty. This is useful for interpreting demand patterns carefully rather than treating correlation as proof of causation.

These two were selected as the most suitable combination: one supports the project's overall notebook-based data analysis workflow, while the other focuses on rigorous statistical interpretation.
